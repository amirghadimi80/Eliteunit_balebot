# 📊 EliteUniteTime Dashboard

داشبورد وب مدیریتی برای سیستم EliteUniteTime

## ✨ ویژگی‌ها

- 🏠 **داشبورد اصلی**: نمای کلی از آمار روزانه، هفتگی و ماهانه
- 👥 **مدیریت کاربران**: مشاهده لیست کاربران، گزارش‌ها و تنبیهات
- 📊 **گزارش‌ها**: فیلتر و جستجوی گزارش‌های روزانه
- ⚠️ **تنبیهات**: مدیریت و پرداخت تنبیهات
- 🔄 **به‌روزرسانی خودکار**: آمار به صورت خودکار هر 30 ثانیه به‌روز می‌شود
- 🎨 **طراحی مدرن**: رابط کاربری تیره و شیک با فونت وزیرمتن

## 🚀 راه‌اندازی

### 1. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 2. تنظیم متغیرهای محیطی

فایل `.env` را ویرایش کنید:

```env
DASHBOARD_PASSWORD=admin1234
DASHBOARD_SECRET_KEY=your-secret-key-here
DASHBOARD_PORT=5000
DASHBOARD_DEBUG=false
```

### 3. اجرای داشبورد

#### روش اول: اجرای مستقیم

```bash
python dashboard/app.py
```

#### روش دوم: استفاده از اسکریپت

**Windows:**
```bash
./run_dashboard.bat
```

**Linux/Mac:**
```bash
./run_dashboard.sh
```

### 4. دسترسی به داشبورد

داشبورد در آدرس زیر در دسترس است:

```
http://localhost:5000
```

رمز عبور پیش‌فرض: `admin1234`

## 📱 صفحات

### 🏠 داشبورد
- آمار کلی (کل کاربران، گزارش‌های امروز، ساعات کل)
- لیست گزارش‌های امروز
- لیست کاربرانی که گزارش نداده‌اند

### 👥 کاربران
- لیست کامل کاربران
- تعداد گزارش‌های هر کاربر
- تعداد تنبیهات پرداخت‌نشده
- بیوگرافی و علاقه‌مندی‌ها

### 📊 گزارش‌ها
- فیلتر بر اساس تاریخ و کاربر
- نمایش ساعات اصلی، فرعی و مجموع
- خلاصه آماری کل گزارش‌ها

### ⚠️ تنبیهات
- لیست تنبیهات پرداخت‌شده و پرداخت‌نشده
- امکان پرداخت تنبیهات
- آمار کلی تنبیهات

## 🔒 امنیت

- احراز هویت با رمز عبور
- Session-based authentication
- تنظیم `DASHBOARD_SECRET_KEY` برای امنیت بیشتر

## 🎨 تکنولوژی‌ها

- **Backend**: Flask 3.0.3
- **Database**: SQLite (مشترک با بات)
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Font**: Vazirmatn
- **Design**: Dark theme, RTL support

## 📝 نکات

1. داشبورد از همان دیتابیس بات استفاده می‌کند
2. تغییرات در داشبورد بلافاصله در بات اعمال می‌شود
3. می‌توانید داشبورد و بات را همزمان اجرا کنید
4. برای استفاده در production، از یک WSGI server مثل Gunicorn استفاده کنید

## 🔧 Production Deployment

برای استفاده در محیط واقعی:

```bash
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 dashboard.app:app
```

یا با استفاده از Nginx به عنوان reverse proxy.

## 🐛 عیب‌یابی

اگر داشبورد اجرا نشد:

1. مطمئن شوید که virtual environment فعال است
2. بررسی کنید که Flask نصب شده باشد: `pip list | grep -i flask`
3. مطمئن شوید که پورت 5000 آزاد است
4. لاگ‌های خطا را بررسی کنید
